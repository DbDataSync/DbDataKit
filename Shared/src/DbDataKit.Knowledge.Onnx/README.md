# DbDataKit.Knowledge.Onnx

The built-in embedding model of the knowledge index (plan 27a KN06): a small sentence-embedding model run in this process with ONNX Runtime, so an install with no embedding server (and no internet) still searches by meaning.

- **`OnnxEmbeddingGenerator`** is an `IEmbeddingGenerator<string, Embedding<float>>`: the text is cut into WordPiece tokens with the model's own vocabulary (lower case, `[CLS]` and `[SEP]`), read on the CPU, the token vectors are averaged over the real tokens (padding does not count) and scaled to length one, as the model's authors do it, so a dot product is a cosine. A text longer than the model reads (256 tokens for the model offered) is cut, keeping the closing `[SEP]`. The id is `builtin/<name>`: the id the index records, so a vector index made with it is rebuilt beside the old one when another model is bound, like any other.
- **`BuiltInEmbeddingModels`** is the catalog. Each row has the dimension, the longest text, the licence (an SPDX name and where it is stated), where the files come from (pinned to a revision) and each file's size and SHA-256. **A model whose licence is not recorded is not offered** (SD12). Today: `builtin/all-minilm-l6-v2` (Apache-2.0, 384 dimensions, English). `Verify` refuses a file that is missing or whose hash is not the recorded one before anything is loaded; `FetchAsync` is for a machine that may reach the internet (each file is checked before it is kept, a half file is never used).
- **`ModelFiles`** is the kind `embedding-model` of plan 30's registry: the files as a published artifact (the manifest `embedding-model.yml` and exactly the catalog's files, each with the catalog's hash: a publish of any other file is refused). An install that cannot reach the internet gets the model from its own state (`Restore` writes the files from the payload store and checks them again); a runner that needs it is sent it like any package.

Not here: binding it from the console (a connection of kind `model-provider` has no `builtin` wire yet, so the Models and Bindings screens do not list it), and the reference vector on Windows (the test records the vector of a fixed sentence and checks it within a tolerance; CI runs it where the model files are present, `DBDATAKIT_TEST_ONNX_MODEL` or `DBDATAKIT_TEST_ONNX_FETCH=true`).
