# DbDataKit.Connections.Http

The client of a connection of kind `http` (plan 27a IX02): `HttpConnections.Create(definition, secrets)` gives an `HttpClient` whose base address is the connection's `endpoint`, whose timeouts are the connection's and whose every request signs in as `sign_in` says.

- **Sign-in methods** (`sign_in.method`): `none`; `api_key` (`key_secret`, sent in the header `name`, default `X-Api-Key`, after `prefix`, or as the query parameter `name` with `in: query`); `basic` (`user`, `password_secret`); `oauth2_client_credentials` (`token_url`, `client_id`, `client_secret_secret`, `scope`, `client_auth: basic|body`): the token is cached until 30 seconds before it expires and **refreshed once** when it expires or the system refuses it with 401 (the request is sent again with the new token; callers that meet the expiry together share one refresh); `client_certificate` (a PKCS#12 `certificate_file`, or `certificate_secret` holding it as Base64, and `certificate_password_secret`); `signed_webhook` (plan 22a GP18 fold: `key_secret` is the secret shared with the receiver; each request's body is signed with HMAC-SHA256 and a timestamp into the header `name`, default `X-DbData-Signature`, as `t=<unix seconds>,v1=<hex>` (`SignedWebhook`); the receiver's replay window is the receiver's).
- **The address is a template** (`EndpointTemplate`, owner decision 2026-11-11): the secret parts of `endpoint` are named placeholders, `https://hooks.slack.com/services/{token}`, bound to secret references in `endpoint_secrets` (`token: secret:dbdatakit:server:connection:ops-slack:token`). A placeholder is in the path or a query value, never in the scheme, host or port (the origin stays visible, so the private-address check and "what does this connect to" work); every placeholder is bound and every binding used. The strict reader **refuses a secret in plain sight** (Slack, Discord, Teams connector and Teams Workflows addresses, a long random path segment, a literal `sig`, `token`, `key`, `secret`, `apikey`, `code` or `signature` query value) and names the part to move into a placeholder. A service nothing classifies can keep the whole address as a secret (`endpoint: secret:...`); it is shown as "address hidden" and is discouraged. The composed address exists only inside the call: the connections list, the Test result and every message show the template, and `HttpConnectionClient.Redact` / `SecretRedaction` take the composed address and each part out of any text that may be shown. `WebhookPatterns` (Slack, Discord, Teams Workflows, the Teams connector) is an editor and validator aid, not a format: a file written by hand with placeholders works the same without it.
- **Webhooks** (`webhook:` section): a Slack, Teams or signed webhook is a connection of this kind; a delivery channel (`DbDataKit.Delivery`) sends through it, keeping the private-address allow-list `webhook.allow_private` and the rule that no redirect is followed.
- **Secrets are references.** They are read when a request is sent and dropped; none is kept, put in a message, a log or a failure. A secret that is not set is a `SecretNotSetException` that names the reference (which holds no value) and classifies as a permanent login failure.
- **TLS** is verified; `tls.verify: false` opts out for that connection only, and `tls.ca_file` trusts that authority for that connection only.
- **Failures** (`HttpFailures`): the shared `ConnectionFailure`, so a retry reads `IsTemporary`. 401 login and 403 permission, 404 and 410 not found, other 4xx syntax: permanent; 429 rate limited, 5xx unavailable, 408, a socket failure and a client timeout: temporary; a refused client of OAuth 2 (400, 401, 403 at the token address) is a rejected login, so a wrong secret is permanent and is not retried. The code is `http-<status>`; no response body or header reaches a message.
- **Test** (`HttpConnectionTester.TestAsync`): signs in (for OAuth 2, gets a token), calls the endpoint (or `test_path` beneath it) once and says whether the system was reached, whether it accepted the sign-in, and what to do, in words, without a value. 404 and 405 count as reached and not refused, and the sentence says to set `test_path`.

A model provider is a connection of another kind (`model-provider`) and has its own adapters (`DbDataKit.Agents.Providers`).
