# Where these documents come from

Imported on 2026-10-27 from `DbDataSync/QueryIntentSpec`, `qis/docs/` at `cddca24` (J01, plan 19). They describe the engine as it was imported, under the names it had there (`Qis.Engine` is now `DbDataKit.Semantic`, `Qis.Contracts` is `DbDataKit.Semantic.Abstractions`; the code is under `DbDataKit/src/DbDataKit.Semantic*`, the schemas under `DbDataKit/src/DbDataKit.Semantic/schemas/`, the fixtures under `DbDataKit/tests/DbDataKit.Semantic.Tests/conformance/`). Paths inside them still read as in the QIS repository. From here the copy in this repository is the one that changes; where a document and the code disagree, the code and the fixtures are the authority (as `handoff.md` says).

Not imported with the engine, on purpose: spreadsheet extraction (`DbDataKit.Semantic.Extraction`), SSAS (`DbDataKit.Semantic.Ssas`, J16), and QIS's own executors.
