## Decisions made in the audit

1. **Build, Sync and Store stay one instance per install** (each "runs once"); groups are a serving-layer concept, and the runner (plan 28) owns scheduled and batch work. No slice. Default taken (owner delegated, 2026-11-09).
2. **Adopting a hand-made data source on a group keeps it the instance's own file** (documented in `DbDataGateway/README.md`); a published data source is the group's. Default taken (owner delegated, 2026-11-09).
3. **Apps stay a module of the serving group, not an instance of their own,** until the module count makes a deployment reason: the module list is configuration, so splitting is deployment, not code. Default taken (owner delegated, 2026-11-09).
4. **Semantic leftovers belong to plan 14a** (SL23 and SL25 semantic state in the Gateway's store, SL27 the combine in a child process, conditional), not to this plan.
